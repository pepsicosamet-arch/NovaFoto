Yes. NOVA Foto is one of the Crafting Apps, which the project describes as free, open-source creative tools. The code is licensed under MIT or Apache 2.0, your choice, and is on [GitHub](https://github.com/pepsicosamet-arch/NovaFoto).

NOVA Foto works offline. Its smart selection tools run on your computer, with no cloud and no account.

The ArtCraft logos in the repository are not open source.

See [Install NOVA Foto](../getting-started/install.md) to download it.
